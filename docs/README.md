## 📋 기능 목록

### 1. 입력
- [x] 방문날짜 입력받기
  - [x] 1 ~ 31 사이 숫자가 아닐시 예외 발생
- [x] 메뉴 입력받기
  - [x] 메뉴판에 없는 메뉴 입력시 예외 발생
  - [x] 메뉴의 개수가 1보다 작을시 예외 발생
  - [x] 중복 메뉴 입력시 예외 발생
  - [x] 음료만 주문하면 예외 발생
  - [x] 전체 주문 수량이 20개를 넘으면 예외 발생
  - [x] 빈 입력, 잘못된 구분자, 숫자 범위 초과 입력 시 예외 발생


### 2. 핵심 기능
- [x] 메뉴판 구현하기
  - [X] 에피타이저 메뉴
  - [X] 메인 메뉴
  - [X] 디저트 메뉴
  - [X] 음료 메뉴
- [X] 사용자 정보를 관리 기능 구현
  - [X] 사용자의 주문 정보를 관리하는 기능 구현
  - [X] 사용자의 할인 적용 정보 관리 기능 구현
  - [x] 사용자의 배지 정보 관리 기능 구현
- [x] 총 주문 금액 계산 기능 구현하기
- [x] 크리스마스 디데이 할인 기능 구현하기
- [X] 평일 할인 기능 구현하기
- [X] 주말 할인 기능 구현하기
- [X] 특별 할인 기능 구현하기
- [X] 증정 이벤트 기능 구현하기
- [X] 배지 부여 기능 구현하기

### 3. 출력
- [x] 날짜입력 안내문자 출력
- [x] 메뉴입력 안내문자 출력
- [x] 주문 메뉴와 수량 출력
- [x] 총주문금액 출력
- [x] 증정 메뉴 출력 (없으면 "없음")
- [x] 적용된 이벤트 출력 (없으면 "없음")
- [x] 총혜택 금액과 할인 후 예상 결제 금액 출력
- [x] 뱃지 출력


### 4. 예외 처리

- [x] 잘못된 입력에는 `[ERROR]` 안내문을 출력하고 해당 입력만 다시 받기
- [x] 주문 재입력 시 이미 입력한 방문 날짜 유지하기

## 책임 나누기
- 입력받기 : InputView
- 출력하기 : OutputView
- 메뉴판 : Menu
- 사용자 정보 저장 : User
  - Order, DiscountEvent, BadgeEvent
  - 사용자의 주문 및 받은 혜택을 모두 종합해 관리함
- 주문받기 : Order
  - 사용자가 입력한 주문, 총 주문금액을 가지고 있음
- 할인적용 : DiscountEvent
  - 사용자가 받을 수 있는 할인을 확인함
- 배지 부여하기 : BadgeEvent
  - 받은 혜택에 따라 배지를 부여함
## ✅ 테스트 계획

- [x] 혜택이 없는 주문 예시의 메뉴, 금액, 배지 출력 확인
- [x] 샴페인 증정 예시의 할인액, 총혜택액, 결제액, 배지 확인
- [x] 잘못된 날짜 및 주문을 입력한 뒤 재입력으로 완료되는지 확인
- [x] 주문 수량 20개, 이벤트 적용 금액 1만 원, 배지 금액 경계값 확인
