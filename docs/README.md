## 📋 기능 목록

### 1. 입력
- [ ] 방문날짜 입력받기
  - [ ] 1 ~ 31 사이 숫자가 아닐시 예외 발생
- [ ] 메뉴 입력받기
  - [ ] 메뉴판에 없는 메뉴 입력시 예외 발생
  - [ ] 메뉴의 개수가 1보다 작을시 예외 발생
  - [ ] 중복 메뉴 입력시 예외 발생


### 2. 핵심 기능
- [x] 메뉴판 구현하기
  - [X] 에피타이저 메뉴
  - [X] 메인 메뉴
  - [X] 디저트 메뉴
  - [X] 음료 메뉴
- [ ] 사용자 정보를 관리 기능 구현
  - [X] 사용자의 주문 정보를 관리하는 기능 구현
  - [ ] 사용자의 할인 적용 정보 관리 기능 구현
  - [ ] 사용자의 배지 정보 관리 기능 구현
- [ ] 총 주문 금액 계산 기능 구현하기
- [ ] 크리스마스 디데이 할인 기능 구현하기
- [ ] 평일 할인 기능 구현하기
- [ ] 주말 할인 기능 구현하기
- [ ] 특별 할인 기능 구현하기
- [ ] 증정 이벤트 기능 구현하기
- [ ] 배지 부여 기능 구현하기

### 3. 출력
- [ ] 날짜입력 안내문자 출력
- [ ] 메뉴입력 안내문자 출력
- [ ] 총주문금액 출력
- [ ] 적용된 이벤트 출력
- [ ] 뱃지 출력


### 4. 예외 처리

## 책임 나누기
- 입력받기 : InputView
- 출력하기 : OutputView
- 메뉴판 : Menu
- 사용자 정보 저장 : User
  - Order, DiscountEvent, BadgeEvent
  - 사용자의 주문 및 받은 혜택을 모두 종합해 관리함
- 주문받기 : Order
  - 사용자가 입력한 주문, 총 주문금액을 가지고 있음
- 할인적용 : DiscountEvent
  - 사용자가 받을 수 있는 할인을 확인함
- 배지 부여하기 : BadgeEvent
  - 받은 혜택에 따라 배지를 부여함
